With the help of AI coding, I recently launched this website for generating causal DAGs.
[https://www.confoundr.com/](https://www.confoundr.com/
)

I remembered when I took classes like EPI201, I had to use PowerPoint just to make my DAG not so ugly. Then, when I was writing some articles, I used LaTeX to generate DAGs. Both of these methods are painful. Therefore, I created this website for people who need to make DAGs. The difference between it and DAGitty is that DAGitty doesn't use the style that we saw in epidemiology. I named this drawer Confoundr. It is a simple drawer, but it is enough to generate some beautiful DAGs for homework and epidemiology research.
